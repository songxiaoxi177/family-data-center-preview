# 家庭数据中心 · 手机公开预览

> 📢 **项目公告**
>
> 这是「家庭数据中心」的**公开手机界面预览站**，用于展示产品设计和交互效果。
>
> **重要说明：公开站只使用演示数据，不包含真实家庭设备数据、账号、密码、API Key 或私人信息。**
>
> 当前版本：**V0.3 UI Preview**

## 当前进度

- 📱 手机优先 Dashboard
- 🏠 家庭总览
- 🖥️ 电脑设备详情
- 📱 手机设备详情
- 💾 NAS 状态
- 📡 家庭网络状态
- 📊 CPU / RAM / 磁盘 / 网络趋势
- 💡 智能分析与异常提示演示
- ☀️ 日间模式
- 🌙 夜间模式
- 📱 跟随系统外观

## 后续计划

公开预览会继续用于展示 UI 更新；真实数据采集、家庭设备连接和历史数据会放在私有的主项目中。

目标数据链路：

```text
家庭设备
   ↓
Windows / NAS / 手机 / 路由器等采集器
   ↓
私有家庭数据中心
   ↓
历史数据库 + 分析引擎
   ↓
手机 Dashboard
```
